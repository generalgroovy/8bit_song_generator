# Changelog

## 1.2 — Instrument interface

Warm faceplate and dark pattern display; fixed voice colors; actual all-bar pitch contours and clip thumbnails. Note names, separate drum-hit marks and keyboard/touch inspection replace anonymous cells. Read-only behavior is explicit. A native in-app Guide and shorter task-oriented documentation explain the workflow. Generation, audio synthesis and project format are unchanged.

## 1.1 — Project protection

Grouped Undo/Redo, guarded autosave recovery, stale-import protection and audio-resume race fixes. Six presets, optional scale-locked harmony, bar inspection, library filtering and bounded loop-length export. [Historical audit](docs/history/ITERATION.md).

## 1.0 — Compact studio

Separated the original single-file app into dependency-free modules. Compact transport and retained pattern rows; shared playback/export audio; connected echo; explicit Stop cleanup; safe names, local saving and JSON backups. Native waveshaping intentionally changed the original crunch timbre. [Historical audit](docs/history/AUDIT.md).
