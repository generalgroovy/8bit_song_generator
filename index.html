8-BIT / QUICK START

From a loop to a song.

  1. Find a sound. Choose a preset and press Play. New pattern keeps your settings; Randomize changes them too.
  2. Shape it. Adjust key, rhythm, melody and sound. Track checkboxes mute voices. The pattern is a read-only preview: select a step for notes, or use arrow keys after focusing a step.
  3. Keep and arrange. Name a loop and Save. Use + Add to put it on the timeline, then choose Timeline and Play. Each clip keeps its own settings.
  4. Take it with you. WAV ↓ exports the editor; Song WAV ↓ exports the arrangement. Project ↓ backs up your editable work. Import restores it.

Saved clips never change with the editor. Load, edit, then Save a new version. Changes during playback restart the loop.
