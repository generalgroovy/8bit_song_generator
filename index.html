How it works

Press Play to hear the starting loop. Make a new pattern, or shape one layer. Save loop keeps a snapshot; Add to arrangement places it in your song. Edit copy opens a separate editor copy. Use arrows or drag to reorder.

Undo/Redo restores library and arrangement actions, loop loads, layer variations, melody changes, New pattern, Surprise me and project imports. Playback stops when restoring. Key, scale, length, seed and melody settings compose fresh notes. Tempo, swing, sound and layer switches keep the notes. Shape one layer changes only the chosen layer and bar, preserving the chord progression and other layers. A little / Half / All replaces that fraction of the differing steps. The starting seed recreates the original full pattern; save a project to preserve variations. Keyboard: Ctrl/Command+Z; Shift+Z to redo outside text fields.

This browser autosaves the complete project. Download project downloads an editable JSON backup with the editor, sounds, actual notes, library and arrangement. Open project replaces the workspace; Undo restores it. Browser storage can be cleared, so keep a downloaded backup for important work.

WAV is a separate offline render, not a live recording: echo/crunch and exact percussion timbre differ. Exports are limited to ten minutes per file. Blue marks the current sixteenth note; green marks active notes. The transport follows each bar.
